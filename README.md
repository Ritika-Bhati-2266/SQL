## 📖 About

This repository is organized into **26 folders**, each dedicated to a specific SQL concept. Whether you're just starting out or looking to solidify advanced skills, you'll find clearly structured scripts, examples, and notes for every topic.

---

## 🚀 Getting Started

### Prerequisites
- A SQL client (MySQL Workbench, DBeaver, or pgAdmin)
- MySQL or any compatible SQL database engine
- No prior SQL knowledge required — start from Topic 01!

### How to Use
1. Clone or download the repository
2. Open the folder for the topic you want to learn
3. Run the `.sql` scripts in your SQL client
4. Follow along with the notes and examples
5. Complete the assignment files to test your understanding

```bash
git clone https://github.com/Ritika-Bhati-2266/SQL.git
cd SQL
```

## 📚 Topics Covered

### 🟢 Beginner (01 – 08)

| # | Topic | Description |
|---|-------|-------------|
| 01 | Create DataBase and Table | Creating databases, defining schemas and data types |
| 02 | Inserting Data in Table | `INSERT INTO` — single and multiple row inserts |
| 03 | Deleting Rows, Columns from Table | `DELETE` and `ALTER TABLE DROP COLUMN` |
| 04 | Update Data on SQL | `UPDATE` with `SET` and `WHERE` clauses |
| 05 | Update Data using SQL Toolbar | GUI toolbar features for updating data |
| 06 | Query Toolbar in SQL | Using the query toolbar and interface features |
| 07 | Alter Column and Data Type in SQL | `ALTER TABLE` to modify columns and change data types |
| 08 | Assignment with Solution | Practice assignments for foundational SQL concepts |

### 🟡 Intermediate (09 – 16)

| # | Topic | Description |
|---|-------|-------------|
| 09 | How to Improve CSV File into SQL | Cleaning and optimizing CSV files before importing |
| 10 | How to Import CSV File Directly into SQL | Importing CSVs using `LOAD DATA` and SQL tools |
| 11 | Type of Operators in SQL | Overview of all SQL operator categories |
| 12 | Comparison Operators | `=`, `!=`, `<`, `>`, `<=`, `>=` for filtering data |
| 13 | Logical Operators | `AND`, `OR`, `NOT` for combining conditions |
| 14 | BETWEEN, LIKE, IN Operators | Range, pattern matching, and set membership |

| 16 | Set Operators | `UNION`, `UNION ALL`, `INTERSECT`, `EXCEPT` |

### 🔴 Advanced (17 – 26)

| # | Topic | Description |
